# لصق سريع

زر عائم كايتحرك فوق جميع التطبيقات. الضغط عليه كايفتح لائحة العبارات ديالك،
والضغط على عبارة كايلصقها مباشرة فخانة الكتابة المفتوحة (واتساب، بحث، أي حقل).

## البنية

كود واجهة واحد، منفذين:

| | نسخة الويب (Netlify) | تطبيق الأندرويد (APK) |
|---|---|---|
| المصدر | `www/` | `www/` + `android/` |
| التخزين | `localStorage` | `SharedPreferences` |
| الزر العائم | ❌ | ✅ |
| اللصق التلقائي | ❌ (نسخ فقط) | ✅ |

مجلد `www/` هو المصدر الوحيد للواجهة — Gradle كاينسخو تلقائياً ل `assets/`
فكل بناء (شوف المهمة `copyWebAssets` ف [android/app/build.gradle](android/app/build.gradle)).
ما تعدلش فـ `android/app/src/main/assets/www/` — كايتمسح.

## 1. رفع الكود ل GitHub

```bash
git init && git add -A && git commit -m "أول نسخة"
```

من بعد صاوب repo جديد فـ github.com ودفع ليه:

```bash
git remote add origin https://github.com/USERNAME/copier.git && git branch -M main && git push -u origin main
```

## 2. تحميل الـ APK

كل دفعة (push) ل `main` كاتشعل البناء تلقائياً. من بعد ~5 دقائق:

1. سير لصفحة **Releases** ديال الـ repo (من الهاتف مباشرة).
2. حمّل `lasq-sari3.apk` من الإصدار **latest**.
3. ثبتو — الجوال غادي يطلب منك تسمح بالتثبيت من مصدر غير معروف، وافق.

> الـ APK موقّع بمفاتيح الديبَگ. صالح للاستعمال الشخصي، ماشي لنشر ف Google Play.

## 3. الإعداد فالجوال (مرة وحدة)

حل التطبيق. غادي تلقى 3 خطوات، كل وحدة عندها نقطة 🟠 ولا 🟢:

1. **الظهور فوق التطبيقات** — إذن عادي، دوس «فتح الإعدادات» وشعلو.
2. **خدمة اللصق التلقائي** — فالإعدادات قلب على «لصق سريع» فـ *الخدمات المثبتة* وشعلها.
   بلا هاد الخطوة الزر كايخدم، ولكن كاينسخ فقط وكتلصق بيدك.
3. **تشغيل الزر العائم** — دوس «تشغيل». الفقاعة الزرقاء غادي تبان.

## 4. الاستعمال

- **جر الفقاعة** لأي بلاصة، كاتلصق فالحافة عند الإفلات.
- **ضغطة** = فتح لائحة العبارات.
- **ضغطة على عبارة** = تنسخ + تلصق فخانة الكتابة المفتوحة.
- **ضغطة طويلة على عبارة** = نسخ فقط، بلا لصق.
- **تعديل العبارات** من داخل اللائحة ولا من التطبيق (إضافة، تعديل، حذف، ترتيب، بحث).

## 5. نشر نسخة الويب على Netlify (اختياري)

اربط نفس الـ repo مع Netlify. الإعدادات موجودة ف [netlify.toml](netlify.toml)
(`publish = "www"`، بلا أمر بناء). كاتنفع باش تعدل العبارات من الحاسوب،
ومن بعد تصدرها بـ **تصدير** وتستوردها فالجوال.

## التطوير محلياً

معاينة الواجهة:

```bash
npx --yes serve www -l 4173
```

بناء الـ APK محلياً (كايحتاج JDK 17 + Android SDK):

```bash
cd android && gradle assembleRelease
```

## الخصوصية

كلشي كايبقى فالجهاز. ما كاين حتى سيرفر، حتى تتبع، وحتى اتصال بالأنترنت.
خدمة إمكانية الوصول كاتقرا حقل الكتابة **غير فاللحظة اللي كتدوس فيها على عبارة**،
وما كاتسجل ولا كاتبعت والو — شوف [PasteAccessibilityService.kt](android/app/src/main/java/com/souheil/copier/PasteAccessibilityService.kt).
